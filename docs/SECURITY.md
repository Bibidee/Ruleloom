# Security

Evidence must be bounded public HTTPS URLs without credentials, fragments, localhost, or common private-address forms. Source bodies are bounded and marked hostile in prompts. Rulebooks are immutable after sealing; a successor carries the previous definition hash. Applicants submit only for their own wallet, evidence is frozen before evaluation, and a pass can be issued once only by its holder from a current ALLOW evaluation. There is no arbitrary creator revocation; expiry is the default revocation path.
