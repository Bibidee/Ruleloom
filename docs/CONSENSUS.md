# Consensus

The leader fetches each frozen public URL and returns a bounded finding for every clause. A validator independently re-fetches each URL and repeats the interpretation. It accepts only matching clause IDs and material findings. Excerpts are accepted only when literal substrings of independently fetched source text. The contract—not the model—maps findings to ALLOW, DENY, or REVIEW. Source failures and malformed output degrade to UNRESOLVED, producing REVIEW where a required clause is unresolved.
